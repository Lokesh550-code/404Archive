# 404 Archive

A curated museum of the internet's weird, wonderful, and fascinating
websites.

404 Archive is a place to discover unusual corners of the internet
through a thoughtfully curated collection of websites. Visitors can
explore exhibits, browse categories, search the archive, and share
interesting finds.

> **Curiosity deserves good design.**

## What to Expect

-   A visual, masonry-style gallery of curated websites.
-   Editorial pages for individual exhibits.
-   Search, category filters, sorting, and random discovery.
-   Community submissions with moderation.
-   Upvotes and content reporting.
-   A responsive, minimal interface.

## Tech Stack

  Area                   Technology
  ---------------------- ---------------------------------------
  Frontend               React, Vite, TypeScript, Tailwind CSS
  Backend                Node.js, Express, TypeScript
  Database               MongoDB, Mongoose
  Data fetching          TanStack Query
  Forms and validation   React Hook Form, Zod
  File storage           Cloudflare R2
  Background jobs        Cloudflare Workers, Queues
  Email                  Resend
